# Rakuten eLoan system
![image](https://hackmd.io/_uploads/HJedaRJ6C.png)

信貸系統開發維護
- 徵審功能，整合聯徵信用資料，縮短貸款審核時間
- 開發客製化報表，提供業務單位分析
- 排查系統問題，確保運作穩定

### Tech stack
前端使用Angular 8搭配PrimeNG 8，並使用VS code作為編輯器，後端系統使用STS編輯器並以Java、Spring Boot開發，透過Jenkins部屬，版本控制使用Gitlab
